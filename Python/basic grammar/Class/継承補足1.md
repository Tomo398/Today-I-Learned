### 実践継承補足

### なぜ継承したものが、メゾットのような「.」がつく?
```python
class CustomScraper(parent_scraper.Scraper):
```
この.が付く意味はファイル名((importした)モジュール名)を指定してあげる必要があるからだ<br>
前半がファイル名で、後半がクラスにあたる

### *args,**kwargsとは?
通常、クラスを継承して、親クラスの初期化変数を使いたい場合はそのまま初期化変数を*init*の隣に書く

しかし、親クラス（Scraper）がどんな初期化変数（引数）を必要としているか分からない時、または親クラスの仕様が今後変わっても対応できるようにするために、この書き方がよく使われる
```python
class CustomScraper(parent_scraper.Scraper):
    def __init__(self, *args, **kwargs):
        super().__init__(*args, **kwargs)
```
*args（可変長位置引数）

    複数の引数を「タプル（順番に並んだリストのようなもの）」として一括で受け取る

    例えば、CustomScraper("URL", 10) と呼び出すと、args の中身は ("URL", 10) になる

**kwargs（可変長キーワード引数）

    timeout=30 のような 名前=値（キーワード引数）の形で渡された複数の引数を、「辞書（ディクショナリ）」として一括で受け取る

    例えば、CustomScraper(timeout=30, retry=3) と呼び出すと、kwargs の中身は {"timeout": 30, "retry": 3} になる


### if __name__ == "__main__":とは
**直接実行されたファイルの __name__ は "__main__"**になるというルールがある

```python
import pandas as pd
def main():
    df = pd.read_csv("ed.csv")
    df.to_csv("df.csv")
if __name__ == "__main__":
    main()
```
それを踏まえて上記のコードを見ると、実際にファイルを動かされたときのみ、main()を実行するという意味になる<br>
これは単に別ファイルがimportでクラスを読み込んだ時などと区別する際に重要になる
