## クラス補足1
### 抽象クラスについて
継承されることを前提として、子クラスに実装を強制させるクラス

```python
from abc import ABC, abstractmethod
class Animal(ABC):

    @abstractmethod
    def speak(self):
        pass

```
**親クラスにABCを継承させて**、任意の関数にデコレータをつけることで、<br>
必ず子クラスでオーバーライドで実装しないとエラーを吐くようになる

基本的にabstractmethodの場合はpassで書くケースが多い
