## スクレイピングコードの親クラス作成について
スクレイピングコードを書くにあたり、共通化して書けることが楽ができ、構造を把握できるため好ましい<br>
パターンとしては、*クラス名だけを書き継承前提で空メゾットを作成する*、*可能な範囲でメゾットを書く*の二通りがある<br>

前者に関してはここでは深く述べず、後者に関して深く述べていきたい

### 共通化して書けるメゾット
主に重要な部分となってくるのは、*find_element(By.,"name")*においてどの要素なら共通化して書けるかということにある。<br>
以下に共通化して書けるメゾットを述べる

### By.CSS_SELECTOR
共通化が最も容易である<br>
basic method.mdのcssセレクタ、部分一致の小見出しのところを見てもらえばわかる通り、<br>
(階層構造(要素の親子関係)自体は同じであることを前提としているため)「*」を使いこなすこと上手くいきやすい

### By.NAME
次に共通化しやすい<br>
name属性はそもそも共通化したわかりやすい属性名で書かれることに加えて、システムの根幹に関わるため変更されていない可能性が高い

### By.PARTIAL_LINK_TEXT
次に共通化しやすい<br>
部分一致を前提とすることが可能なためある程度は共通化できるが、表記ゆれが存在するため慎重に判断を期す必要がある
