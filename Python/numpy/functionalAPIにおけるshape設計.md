## FunctinalAPI内部におけるshape設計
### 軸の意味
*Conv1D*なら基本的に(batch,time,features)となる<br>
これは実質的に、1サンプル当たりのshapeとなる<br>
仮に、(None, 48, 20)を下記の*Conv1D*に通すとすると、
```python
layers.Conv1D(filters=32,kernel_size=3,padding="same")
```
このときの*Conv1D*の意味として、時点の次元ではフィルタが動かせるけど、特徴量次元は固定で動かせないことを意味している<br>
よって、当然フィルタは横は特徴量数は固定である<br>
フィルタが動かせるのはあくまで時点次元方向だけ<br>
この際、フィルタの縦(時点数)はカーネルサイズで増やすことができる<br>
shapeは(None, 48, 32)となり、理解の仕方として、特徴量軸を32個の学習表現に変換したと考えるといい<br>
(フィルタは各フィルタによって重視すべき表現が異なってくるという意味では、パラレルワールドっぽい)

### 学習表現軸の増加
```
input
(None, 48, 20)

Conv1D(32)
↓
(None, 48, 32)

Conv1D(64)
↓
(None, 48, 64)

Conv1D(128)
↓
(None, 48, 128)
```
このようにフィルタを増やせばどんどん学習表現軸が増えていく<br>
最初のフィルタ通過後は、単なる**異なる視点において、その時点に存在する各特徴量の要約**(学習された重み付き合成)だったのが、<br>
その要約同士でフィルタをかけることでより複雑な表現(要約)を学習していく<br>

### Pooling層による時点数削減
基本的にfilterを増やせば増やすほどテンソルが巨大化していくが,<br>*Pooling層*を挟み、代表値(最大値、平均値)を抽出することで、時間方向は圧縮しながら、表現の種類を増やすことができる(このメリットは?)

### 残差結合
残差結合では*layers.Addする瞬間のshape*が完全一致すればよい<br>
基本的にCNNでは残差結合はフィルタを通す前と後で加算対象のshapeが変わってしまう<br>
そこで以下のようなコードを書くことでサイズを合わせるとよい
```python
    if shortcut.shape[-1] != filters:#1層目だけshapeが合わないのでその対策
        shortcut = layers.Conv1D(filters, 1, padding="same", use_bias=True, name=f"shortcut_30m_{i+1}")(shortcut)
        shortcut = layers.BatchNormalization(name=f"shortcut_bn_30m_{i+1}")(shortcut)  
    x_30m = layers.Add(name=f"residual_30m_{i+1}")([x_30m, shortcut])
```
(厳密な残差結合ではなくなるが、カーネルサイズを1にすることで時点を混ぜない結合をしている)

### 異なる入力の結合
*layer.concatenate(axis=-1)[]*を使うが、この際、(結合する)最後の軸(学習表現数)以外は一致している必要がある<br>

#### A.各時間足をベクトルに潰してから結合
各特徴量マップをそれぞれ平均をとることで、時間足をベクトルに潰す<br>
この手法は*GlobalAveragePooling1D*である

#### B.Flattenしてから結合
単に1次元に削減する、これはパラメータが急激に増加するため注意
```
30m : (48,128) → Flatten → (6144)
1h  : (24,128) → Flatten → (3072)
3h  : ( 8,128) → Flatten → (1024)
```

#### C.時間軸をそのものを徐々に揃えてから結合
事前に*MaxPooling*などで時間軸を揃えてから結合する<br>
この場合、時点数を揃えられるので、同じ時間区間でそれぞれ何を学習したか対応付けられる
```
30m : 48時点
↓ 6個ずつ圧縮
8時点

1h : 24時点
↓ 3個ずつ圧縮
8時点

3h : 8時点
↓
8時点
```

#### D.アップサンプリングする
特徴量マップのサイズを大きくする手法として補完して大きくする*Upsampling*や<br>入力サイズに対して大きなフィルタを使うことで出力サイズを大きくする*Conv1DTranspose*などがある<br>
これらを使う際は、いずれもカーネルサイズやストライドに気を付ける必要がある<br>
