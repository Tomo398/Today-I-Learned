### 前提
用語の整理（10バッチの場合）

    1バッチ (Batch): 全データを10分割したうちの「ひと塊」のこと。

    1イテレーション (Iteration / Step): 1つのバッチを学習して、重みを1回更新すること。

    1エポック (Epoch): 10個のバッチすべてを学習し終えて、全データを1周すること。

つまり、「10イテレーション ＝ 1エポック」 という計算になる

### 頻出メゾット
import tensorflow as tf
import keras as tfk  # tensorflow.keras ではなく直接 keras
from keras import layers, models

テンプレートimport文

.shape:次元数がわかる
(奥行数、行、列)

tf.keras.layers.,,,(..., input_shape=(28, 28)):あえて入力の形式を明示することで、summaryが見やすくなる

tfk.Sequential([]):kerasによる簡易的な枠組み、中に活性化関数や畳み込み層、出力層、ドロップアウトなどを入れる

基本的には、小規模モデルなら**2~3層**程度書く

tfk.layers.Reshape((縦、横、チャネル)):
通常画像データは2次元なため、CNNを使うときはチャネルの次元を付け足す必要がある

tfk.layers.Conv2D(filters,kernel_size,padding="same"):畳み込み層、フィルターの数(出力チャネル数(重みの異なるフィルタを何枚使うか))とフィルタの次元を決める

padding=*"same"*にすると、入力と出力の次元を常に一定に保ってくれる、不足している部分は0で埋めてくれる*"valid"*(デフォルト)だと特にpaddingは行われず、どんどん次元が小さくなっていく

※適切な数値について
フィルタ数は(16→)32 → 64 → 128 (→ 256 → 512)
と層が増すにつれて増やすのが一般的

カーネルサイズに関しては、**必ず奇数**(1,1)などにするのが通例。
黄金律は(3,3)

迷ったら (3,3)でまず組んでみて、精度が上がらない場合に「最初の1層だけ(5,5)にしてみる

tfk.layers.Maxpooling2D(pool_size):プーリング層、画像データで良く使われる

tfk.layers.AvgPool2D(pool_size):プーリング層、プーリングの次元を決める、画像データではあまり使われない、最終層で稀に使う

※基本的にpool_sizeは通例(2,2)(かつストライドは(2,2)(勝手にストライドも2,2になる))

tfk.layers.Flatten():バッチサイズ以外の次元を1つのベクトルにする

tfk.layers.GlobalAvaragePooling2D():バッチサイズ以外の次元を1つのベクトルにする,flatten()と異なり、各チャンネルの平均を渡すため、出力の個数が減る

tf.keras.layers.Dense(units=128, activation = "relu"):総和に対して重みを変化させることで次元を落とす、また活性化関数もここで指定する

数式イメージ
$$y_j = \phi (\sum_{i=1}^{Flattensize}x_iw_{i,j}),j=1,...,128   $$

tfk.layers.Dropout(0.2):ドロップアウト率を指定する

.summary():モデルを俯瞰することができる

tfk.losses.(任意):損失関数の設定、クロスエントロピー、最小二乗誤差などいろいろある

.compile(optimizer="adam",loss=,metrics=["accuracy"]):更新率、損失関数、目安指標を決める

.fit(x,y,epochs=,validation_data=,callbacks=[early_stopping]):何回逆誤差伝播法を繰り返すか指定する

仮に、x,yともにtf.datasetにしている場合、yは書く必要がない

.evaluate(x,y,verbose=):テストデータの評価に使われる

.predict():実際に分類(予測)をし、その値を代入する

.argmax(axis=1):最大値がある位置を返す(取り出す)、縦(サンプル数)でそれぞれ取り出したいならaxis=0,横(クラス数)でそれぞれ取り出したいならaxis=1となる
今回は、axis=1なので、各行で最大の列番号(クラス)を返すという意味になる

confution_matrix(y_test,y_pred1,labels=(np.arange(10))):混合行列を作る、ラベルを明確に示した方が好ましい
