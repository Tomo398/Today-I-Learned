## TensorFlow公式　初中級

### csvデータを読み込む
大分すると、二つの手法がある。一つは、既存ライブラリ(pandas)を使いRAMに書く方法だ。二つ目は、直接RAMを使うことを避け、tf.dataset型として読み込む方法だ。

また、tf.dataset型として読み込む方法も4つの種類に分けることができる。一つは、*インメモリ(既にDRAMに載っているデータ)*からtf.datasetに変える方法だ。二つ目は、単一のファイルデータを読み込む際、*バッチサイズを指定する*ことで、徐々にDRAMに載せる方法だ。三つ目は、学習の際、エポックごとに毎回データを読み込む(必要があり)と時間がかかってしまうため、*1回目の学習の際に使ったデータをキャッシュ(DRAMかSSD)に保存*し、高速で読み出せるようにする手法だ。最後に、*複数のcsvから並列*で読み込む手法もある。

3つ目の手法は結局DRAMに載せる手段をとることがあるため、pandasと変わらないという指摘があるかもしれない。しかし、このメゾットはあくまで任意であり、DRAMに載せきれないようなデータなら引数を指定し、SSDに保存することもできる

pandasによる読み込み方法は既知のため、概ね省略する,


※一般的にキャッシュというとSRAM(容量数MB)を指すが、この文脈ではDRAMあるいはSSDを指す

### 混合型データ(読み込む方式はpandasだが基本Keras(Fanctional API)のやり方)
Tensorflowはデータの型と範囲を必ず統一しなければならない。
型の場合は、全てfloat32かint32が一般的である。
範囲に関しても揃えた(標準化(バッチ正規化))方が学習が安定する
欠損値に関してもnaを許さないので補完、もしくは削除する必要がある

#### input = tf.keras.Input()
これ自体は計算は行わないが、宣言的な役割(計算式レシピ)を担う
引数としては、*shape(バッチサイズは含めない)*,*name(データの名前、列名)*,*dtype(データの型)*,*batch_size(デフォルトはNone)*を使う。

※shapeはスカラーを入れたいときはshape=(),(1次元)ベクトルを入れたいときはshape=(1,)と書く

コード例:
```
inputs = {}

for name, column in titanic_features.items():
  dtype = column.dtype
  if dtype == object:
    dtype = tf.string
  else:
    dtype = tf.float32

  inputs[name] = tf.keras.Input(shape=(1,), name=name, dtype=dtype)

inputs
```

上記のようにデータセットに対して一気にInputオブジェクトを作成できる

その作成した辞書から、数値列、文字列等に仕分けるには、下記のように書く
```
# 空の辞書を用意
numeric_inputs = {}

# inputs（すべての入力）を1つずつ取り出してループで回す
for name, input_tensor in inputs.items():
    if input_tensor.dtype == tf.float32:
        numeric_inputs[name] = input_tensor
```
#### layers.Concatenate()
個別の数値列をそれぞれで受け取ることができないので、一つの横長の数値列として受け取るための関数(ただのpd.mergeのようなもの)

注意として、これはまだ計算しておらず、これもまだ宣言のようなもの
基本的に、実際に計算するのは**adapt**である

引数は二つあり、一つはaxis(デフォルトは-1(横方向)なため基本空欄でいい)、もう一つは合体させたい中身(テンソルのリスト)である

二つ目の引数は*(list(numeric_inputs.values()))*のように書く

####  layers.Normalization()
正規化レイヤー、*norm = layers.Normalization()*のようにインスタンス化して使う

この後、*norm.adapt(実データ)*で計算した後、*norm(x)(concatenateしたもの)*に渡すことで回路の設計図として渡す

#### layers.StringLookup()
これは文字列を整数に変換するレイヤー、主な引数は*vocabulary(登録する単語)*である

vocabularyは一つ一つ書くより、*np.unique(titanic_features[name])*などと書いて配線を繋げた方が楽

#### layers.CategoryEncoding()
*layers.StringLookup()*で数字に変えたものを、更に0,1にかえてしまうレイヤー、主要引数は*num_tokens(何種類変換する必要があるか)*,*output_mode(出力形式(one_hotかmulti_hot))*

### tf.keras.Model()
設計図を一つのモデル(製品)として完成させる関数、
引数は**inputs(モデルの入り口、最初に定義したInput)**,**outputs(モデルの出口、最後に合体させたテンソル)**,*name(任意の名前をつけもよい)*

#### tf.keras.utils.plot_model()
作ったモデル(tf.keras.Model)を俯瞰するためのplot
引数は*model*,*rankdir(図の方向(TBorLR))*,*show_shape(各レイヤーのshape表示(True or False))*,*show_dtypes(各レイヤーのデータ型表示(True or False))*


※この方法はあくまで*Functional API*の方式を採用したやり方である
*Sequential API*はレイヤーを順番に積み重ねるだけでシンプルで書きやすいが、残差接続や複数出力などを行おうとするとレイヤーを関数のように組み合わせる必要が出てくる。そのための慣れのためのチュートリアルなのかもしれない

### tf.dataとして読み込む
### tf.data.Dataset.from_tensor_slices()
メモリ上のデータ(numpy,リスト)をDataset型に変換するために使われる

slicesの由来は以下の通りである

(100,4)の形のNumpy配列があったとする、これをfrom_tensor_slices()を通すと、(4,)の形のデータ(1行分)(次元が一つしかなく、そこに4つの要素がある)を100回連続で送り出すオブジェクトになるから

※(4)でなくて(4,)と書くのはスカラーと区別するため、(可能なら(4)と書くべき)

### 単一のファイルから
初級3,5で記述しているとおり、 *tf.data.experimental.make_csv_dataset()*を使用する
細かい使い方や引数は前述したものを参照されたい。

ここで注意したいのは、num_epochsの引数指定だ。
流儀として、*1.データ側を無限にする*と*2.学習側(Keras)に任せる*という方法がある。

1の場合は、
make_csv_dataset(..., num_epochs=None) とし、*model.fit(epochs=10, steps_per_epoch=100)*のように、学習側で*「何回ステップを踏んだら1エポックとみなすか」*を指定する

2の場合は、*num_epochs=1* にしておき、*model.fit(dataset, epochs=10)* と書く。
この場合は、Kerasは「データが1周終わった」ことを検知して、自動で次のエポックを開始してくれる。

データが無限に湧き出るような場合(リアルタイムデータなど)は、1が使われる場合もあるが、基本的に2が推奨される。

###　複数csvファイルの並列読み込み
*tf.data.experimental.make_csv_dataset()*を使うが、引数に気を付ける必要がある。

#### file_pattern
"fonts/*.csv"のようにパスと(複数のファイルが読み込めるように)ワイルドカードを渡す

#### num_parallel_reads
同時にいくつかのファイルを読みにいくか,*tf.data.AUTOTUNE*を指定する
