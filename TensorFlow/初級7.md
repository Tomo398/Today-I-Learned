### ハイパーパラメータの種類
2種類ある

1.*モデルハイパーパラメータ*
非表示レイヤーの数と幅などモデルの選択に影響する

2.*アルゴリズムハイパーパラメータ*
確率的勾配降下法の学習率やk近傍法のkの数など学習アルゴリズムの速度と質に影響する

※ハイパーパラメータチューニングを行うモデルを構築する際ハイパーパラメータ検索空間を定義する、ハイパーチューニング用にセットアップするモデルを*ハイパーモデル*と呼ぶ

*ハイパーモデル*の定義は「モデルビルダー関数(自作関数)」か「Keras Tuner APIのHyperModelクラスをサブクラス化」を使う

シンプルなモデルの時にはモデルビルダー関数が使われ、複雑なモデルほど継承を使う,今回はモデルビルダー関数の紹介に留める


### モデルビルダー関数のテンプレート
import keras
from keras import layers, regularizers

def model_builder(hp):
    """
    正則化項とドロップアウトの最適化を含むモデル構築関数
    """
    # 0. モデルのインスタンス化(後から色々な層を追加する)
    model = keras.Sequential()
    
    # 1. 正則化強度の探索範囲（対数スケールが定石）
    # 非常に小さい値から、影響が大きくなる 0.01 程度までを探索
    hp_l2_value = **hp.Float**('l2_regularization', min_value=1e-5, max_value=1e-2, sampling='log')
    
    # 2. 中間層の定義
    # ユニット数とセットで「正則化」を適用
    model.add(layers.Dense(
        units=**hp.Int**('units', min_value=32, max_value=512, step=32),
        activation='relu',
        kernel_regularizer=regularizers.l2(hp_l2_value) # 重みに対するL2正則化
    ))
    
    # 3. ドロップアウト率のチューニング
    # 0.0（なし）から 0.5（半分）の間で調整
    hp_dropout = **hp.Float**('dropout_rate', min_value=0.0, max_value=0.5, step=0.1)
    model.add(layers.Dropout(rate=hp_dropout))
    
    # 出力層（例として10クラス分類）
    model.add(layers.Dense(10, activation='softmax'))

    # 4. 学習率のチューニング
    hp_lr = **hp.Float**('learning_rate', min_value=1e-4, max_value=1e-2, sampling='log')

    # 5. コンパイル
    model.compile(
        optimizer=keras.optimizers.Adam(learning_rate=hp_lr),
        loss='sparse_categorical_crossentropy',
        metrics=['accuracy']
    )

    return model

探索のために使われているメゾットは以下の通り
#### hp.Int()
整数の範囲を指定、層のユニット数、フィルタ数

#### hp.Float()
浮動小数点の範囲を指定、学習率、ドロップアウト、学習率、正則化係数

#### hp.Choice()
リストから値を選択、活性化関数、最適化手法

#### hp.Boolean()
バッチ正規化を入れるかどうか

### Keras Tunerの使用
Tunerの種類は4つある。今回は最も一般的かつ良く使われる*Hyperband*を使用する
このチューナーをインスタンス化してハイパーチューニングを実行する

### kt.Hyperband()
主要引数
#### hypermodel
モデルビルダー関数かHyperModelクラスのインスタンスを指定する

#### objective
最適化したい指標を指定する(主にval_loss)

#### max_epochs
一つのモデルに対して実行する最大エポック数。
少し多めに設定して、EarlyStoppingと併用するのが推奨されている

#### factor
各ラウンドで、残すモデルの数とエポック数を削減する倍率(デフォルトは3)

仮にmax_epochs=81、factor=3とした場合、最初に試すべきモデルは81個になり、最初に残るモデルは27個(3分の1)になる。残ったモデルが少なくなったので、一つのモデルあたりに試せるエポック数が増加する
そして、最終的には一つのモデルになり、そのモデルにつきエポック数が81となる

#### directory
ログや訓練結果を保存するルートディレクトリのパス

#### project_name
directory内に作成される、このフォルダ専用のフォルダ名

#### seed
再現性のための乱数シード

### tuner.search()
基本的に引数や使い勝手はfitと同じ、しかし、*tf.keras.callbacks.EarlyStopping*をインスタンス化し、引数に入れるのを忘れないようにした方がいい

### tuner.get_best_hyperparameters(num_trials=1)[0]
良いハイパーパラメータを持ってくる、場所の指定は*num_trials=1*でまず成績1位のハイパーパラメータを持ってくる
また、リストではなくオブジェクトが欲しいので[0]で指定してあげる

### model = tuner.hypermodel.build(best_hps)
最高のハイパーパラメータでできたモデルを格納する
訓練データ自体の最適なエポック数はやった結果のmaxを取ってきたり、早期停止を利用する(わりかし脳死)
